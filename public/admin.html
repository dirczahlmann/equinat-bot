⚙️ Einmalige Einrichtung erforderlich

Damit das Admin-Panel deine Tester-Daten anzeigen kann, brauchst du einen Netlify Personal Access Token und die Form-IDs.

  1. Öffne app.netlify.com/user/applications
  2. Klicke "New access token" → Name: "EQUINAT Admin" → erstellen → Token kopieren
  3. Gehe zu deinem Projekt → Forms → Klick auf eq-messages → ID aus URL kopieren (lange Zeichenfolge nach /forms/)
  4. Optional: ID von equinat-tester auch kopieren
  5. Hier unten eintragen und speichern (wird verschlüsselt im Browser gespeichert)

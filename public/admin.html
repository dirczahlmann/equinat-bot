Wichtig: Closed Beta — Code-System
Beim Klick auf ✓ Freischalten wird automatisch ein 6-stelliger Beta-Zugangscode generiert (z.B. EQ-7K3M). Diesen kopierst du und schickst ihn dem Tester per Email.

Der Tester gibt den Code + seine Email auf der Bot-Startseite ein und ist freigeschaltet.

Code revoken: Im Detail-Modal eines Testers gibt es einen "Code widerrufen" Button — der setzt den Status auf revoked und der Bot sperrt den Tester.

Admin-Zugang: Geschützt durch Netlify Basic Auth (siehe netlify.toml). Username + Passwort werden serverseitig validiert. Browser-Login-Dialog erscheint beim Aufruf von /admin.html.
